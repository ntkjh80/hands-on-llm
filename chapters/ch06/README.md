## 공부 순서

먼저 학습 노트의 출력 제어까지 읽고 시각화 첫 실험을 조작한다. 프롬프트 모듈과 예시를 읽은 뒤 자신의 과제로 짧은 입력 계약을 작성한다. 추론 전략과 출력 검증을 읽은 다음 Python 실습을 실행하고 복습 문제를 푼다. 모르는 내용은 이 6장 전용 챗에서 해당 절 제목이나 문제 번호를 붙여 질문하면 이어서 공부하기 쉽다.

```bash
python3 chapters/ch06/lab.py
```

실습은 교육용 확률·문자열·탐색 모형이다. 실제 Phi-3 추론이나 GPU 실험은 실행하지 않았으며, 출력된 수치를 모델 성능으로 해석하지 않는다. HTML의 계산·이벤트 연결과 데스크톱·390px 화면, 입력 조작을 확인했다.
