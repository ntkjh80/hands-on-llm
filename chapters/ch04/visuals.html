CHAPTER 04 · TEXT CLASSIFICATION

숫자를 움직이며 이해하는 텍스트 분류

임계값은 오류의 종류를 바꾸고, 라벨 벡터는 제로샷 분류의 기준점을 정합니다.

모든 점수·벡터는 원리를 보여주기 위해 만든 교육용 가상 데이터입니다. 실제 LLM 출력이나 영화 리뷰 벤치마크 결과가 아닙니다. 외부 연결 없이 동작합니다.

1. 임계값과 혼동 행렬

리뷰 10개의 점수는 고정되어 있습니다. 임계값 이상을 긍정으로 분류할 때 어떤 문서가 넘어가는지 관찰하세요.

원형: 실제 긍정사각형: 실제 부정점선 오른쪽: 긍정 예측
실제 ↓ / 예측 →부정긍정
부정TN3FP2
긍정FN2TP3
긍정 precision0.600
긍정 recall0.600
긍정 F10.600
accuracy0.600

분모가 0인 precision·recall·F1은 이 실험에서 0으로 표시합니다. 임계값 선택은 실제 과제에서는 validation으로 해야 합니다.

확인할 질문

임계값을 0.50에서 0.80으로 올렸을 때 FP와 FN이 어떻게 변하나요? 임계값 0에서는 recall이 1인데 왜 정확도도 1이 되지는 않나요? 0.95에서 1.00으로 올리면 긍정 예측이 사라지며 precision은 수학적으로 정의되지 않습니다. 이 실험의 표시 정책과 구별해 설명하세요.

2. 문서와 라벨 벡터의 방향

문서의 방향과 길이를 바꾸고 두 라벨과의 코사인 유사도를 비교합니다. 라벨 좌표 선택은 설명 문구가 달라졌을 때 기준점이 바뀔 수 있다는 원리를 나타냅니다.

문서 좌표

최대 유사도 라벨

막대는 −1부터 1까지의 값을 0~100% 길이에 대응시킵니다. 유사도는 확률이 아닙니다.

확인할 질문

방향을 고정하고 길이만 바꾸면 어떤 값이 유지되나요? 설명 A에서 문서 방향이 45°일 때는 두 유사도가 같습니다. 이 실험은 동점을 표시하며 임의로 정답을 확정하지 않습니다. 원문처럼 argmax를 사용한다면 후보 순서가 동점 결과에 영향을 줄 수 있습니다.

3. 생성 문자열을 라벨로 읽기

문자열을 선택해 허용 집합 검사와 무조건적인 else → 긍정의 차이를 확인하세요. 이 문자열은 사람이 만든 테스트 입력입니다.
