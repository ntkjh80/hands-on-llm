1장 시각 실험

입력이나 가중치를 바꾸고, 수치와 그림이 함께 달라지는 것을 관찰하세요.

모든 문장·벡터·점수는 교육용 가상 데이터입니다. 실제 LLM이나 API를 호출하지 않으며, 외부 네트워크 없이 동작합니다. 키보드로 입력 상자, 선택 메뉴, 슬라이더와 버튼을 조작할 수 있습니다.

실험 1. 순서를 바꾸면 빈도 벡터가 달라질까

공백을 기준으로 토큰을 나눕니다. 한국어 형태소 분석기는 아닙니다. A와 B의 단어 순서만 바꾸거나 “고양이”를 반복해 보세요.

A의 횟수B의 횟수

가로 막대 길이 = 등장 횟수. 두 문서가 공유하는 최대 횟수에 맞춰 길이를 조정합니다. 같은 벡터라도 주어와 목적어가 바뀌면 문장 의미는 달라질 수 있습니다.

실험 2. 어텐션은 여러 벡터를 어떤 비율로 섞을까

입력 상태 h₁=(1,0), h₂=(0,1), h₃=(1,1)을 사용합니다. 점수 [1, 2, s₃]에 softmax를 적용해 합이 1인 가중치를 만들고 문맥 벡터를 계산합니다. 이 점수는 학습된 모델 값이 아닙니다.

관찰 질문: s₃가 가장 작아도 가중치가 정확히 0이 되나요? 점수와 정규화된 가중치가 같은 값인가요?

실험 3. 다음 토큰을 하나씩 고르면 문장이 된다

작은 여섯 문장에서 센 다음 토큰 빈도를 사용합니다. 이 bigram 모형은 바로 앞 토큰 하나만 봅니다. 현대 LLM의 문맥 이해를 재현하지 않습니다.

통계를 만든 여섯 문장

오늘 날씨가 좋다 / 오늘 날씨가 좋다 / 오늘 날씨가 흐리다 / 오늘 기분이 좋다 / 내일 날씨가 춥다 / 내일 기분이 좋다

매 단계에서 가장 높은 확률을 선택합니다. 동률이면 정해 둔 어휘 순서를 따릅니다. <끝>은 문장 종료를 뜻하며 화면의 문장에는 붙이지 않습니다. 상한을 늘려도 종료 토큰을 고르면 그때 멈춥니다.
