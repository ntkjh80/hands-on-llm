# 12장 복습 문제와 해설

[전체 목차](../../README.md) · [학습 노트](study.md) · [강의안](lecture.md) · [강의 대본](lecture-script.md) · [시각화](visuals.html) · [실습](lab-guide.md) · [복습 문제](quiz.md)

문제를 먼저 풀고 접힌 해설을 연다. 총 18문제이며 개념, 손계산, 디버깅, 설계를 섞었다. 각 문제는 5점으로 채점할 수 있으며 총 90점이다. 계산의 마지막 소수점보다 계산 대상과 가정을 정확히 설명하는 것을 우선한다.

## 1. 세 단계의 데이터 구분

사전학습, SFT, 선호도 학습에 필요한 데이터 한 행을 각각 예시로 쓰고, “사전학습에는 라벨이 없다”가 어떤 의미인지 설명하라.

<details><summary>해설과 채점 기준</summary>

사전학습은 “오늘은 비가 온다”와 같은 텍스트에서 앞 토큰으로 다음 토큰을 예측한다. SFT는 “날씨 문장을 요약하라 → 비가 옵니다” 같은 지시·응답 쌍이다. 선호도 학습은 같은 질문에 대한 chosen·rejected와 선호 표시를 갖는다. 사전학습에 사람이 붙인 별도 라벨은 없어도 목표 토큰은 텍스트 자체에서 만든다. 세 예시 각 1점, 자기지도 신호 설명 2점.

</details>

## 2. SFT 손실 손계산

정답 응답 세 토큰의 조건부 확률이 0.8, 0.5, 0.25다. 전체 응답 확률, 자연로그 기준 평균 NLL, 퍼플렉서티를 계산하라.

<details><summary>해설과 채점 기준</summary>

전체 확률은 `0.8×0.5×0.25=0.1`이다. 평균 NLL은 `-log(0.1)/3≈0.767528`, PPL은 `exp(0.767528)≈2.154435`다. 확률을 더하지 않는 이유까지 설명한다. 전체 확률 1점, 평균 NLL 2점, PPL 1점, 조건부 확률의 곱 설명 1점.

</details>

## 3. 손실 마스크 디버깅

입력은 사용자 질문, 응답, 패딩으로 구성되어 있다. “응답만 학습”하려고 사용자 질문의 attention mask를 0으로 바꾸었다. 이 수정은 올바른가?

<details><summary>해설과 채점 기준</summary>

일반적인 의도에는 맞지 않는다. 응답은 질문을 문맥으로 보아야 한다. 질문의 손실 위치를 제외하는 것과 attention에서 질문을 안 보게 하는 것은 다르다. 질문은 attention 가능한 문맥으로 유지하고, 응답만 학습하려는 경우 프롬프트 위치의 label/loss mask를 제외한다. 패딩은 attention 및 손실 처리에서 적절히 제외한다. 두 마스크의 목적 구분 3점, 올바른 수정 2점.

</details>

## 4. LoRA 차원과 파라미터 수

입력 512차원, 출력 1024차원인 선형층에 rank 8의 LoRA를 적용한다. 열벡터 convention에서 A, B, BA의 차원과 학습 파라미터 수를 구하라. 기반 가중치는 없어지는가?

<details><summary>해설과 채점 기준</summary>

A는 8×512, B는 1024×8, BA는 1024×512다. 학습 파라미터는 `8×512+1024×8=12,288`개다. 원래 524,288개 가중치는 고정된 채 남는다. 차원 2점, 개수 2점, 고정 기반 가중치 설명 1점.

</details>

## 5. rank 1의 표현 제약

B=`[[1],[2]]`, A=`[[3,4,5]]`일 때 BA를 계산하라. 같은 B와 임의의 A로 두 번째 행만 `[6,8,11]`로 바꿀 수 있는가?

<details><summary>해설과 채점 기준</summary>

BA는 `[[3,4,5],[6,8,10]]`이다. B를 고정하면 두 번째 행은 첫 번째 행의 두 배이므로 마지막 원소만 독립적으로 11로 만들 수 없다. 저랭크 변화량의 자유도 제약을 보여 준다. 계산 2점, 불가능한 이유 2점, 자유도 해석 1점.

</details>

## 6. rank를 늘리는 실험의 통제

r=8, α=16인 실험과 r=16, α=16인 실험을 비교하고 “차이는 rank뿐”이라고 했다. 무엇이 함께 변했는가? rank의 영향을 더 분리하려면 어떻게 설계할 수 있는가?

<details><summary>해설과 채점 기준</summary>

원래 LoRA 스케일 α/r가 2에서 1로 변한다. rank와 스케일의 효과가 섞였다. α/r를 일정하게 유지하려면 두 번째 α를 32로 설정하는 비교를 추가할 수 있다. 그래도 파라미터 수·초기화·최적화 경로가 달라지므로 완벽히 동일한 실험이라고 주장하지 않는다. 스케일 계산 2점, 통제안 2점, 남는 차이 설명 1점.

</details>

## 7. QLoRA 설명 고치기

“QLoRA는 전체 모델의 모든 파라미터를 4비트로 업데이트하기 때문에 훈련 메모리가 정확히 원래의 4분의 1이다.” 이 문장에 있는 두 가지 문제를 고쳐라.

<details><summary>해설과 채점 기준</summary>

기반 가중치는 저비트로 저장하고 고정하며 LoRA 파라미터를 학습한다. 저장 dtype과 계산 dtype이 다를 수 있다. 훈련 메모리에는 활성값, 기울기, 옵티마이저 상태, 양자화 메타데이터 등이 있어 전체가 정확히 4분의 1이 된다고 볼 수 없다. 학습 대상 2점, dtype 구분 1점, 전체 메모리 설명 2점.

</details>

## 8. 블록별 양자화의 장단점

대부분 가중치는 0 근처인데 한 값만 8이다. 하나의 범위로 균일 양자화하는 것보다 블록별 범위가 유리할 수 있는 이유와 그 비용을 설명하라.

<details><summary>해설과 채점 기준</summary>

전역 범위는 이상값 때문에 대표값 간격이 커져 작은 값들 사이의 차이를 잃을 수 있다. 블록별 스케일은 이상값의 영향을 해당 블록에 제한한다. 반면 블록마다 스케일 등 메타데이터가 필요하며 여전히 양자화 오차가 남는다. 범위·해상도 연결 3점, 저장 비용과 잔여 오차 2점.

</details>

## 9. 배치와 warmup 계산

장치 한 개, 배치 2, gradient accumulation 4, max_steps 200, warmup_ratio 0.1이다. 완전한 업데이트의 유효 배치와 warmup step 수는 얼마인가? cosine scheduler만 설정해도 같은 warmup이 생기는가?

<details><summary>해설과 채점 기준</summary>

유효 배치는 8, warmup은 20 step이다. cosine은 감소 일정의 종류이며 warmup을 별도로 설정해야 한다. 데이터 패킹·마지막 배치 등 실제 처리 조건은 별도 확인한다. 두 계산 각 1점, 별도 warmup 설명 2점, 조건 언급 1점.

</details>

## 10. 평가 설계 사고 과제

한국어 초보자용 기술 설명 도우미를 SFT했다. 훈련 PPL이 낮아졌고 영어 수학 벤치마크도 올랐다. 출시 판단을 위해 추가할 평가 네 가지와 각각의 이유를 제시하라.

<details><summary>해설과 채점 기준</summary>

예: 한국어 독립 질문의 사실성, 용어 설명의 이해 가능성, 요청한 출력 형식 준수, 근거 없는 주장·오답 처리, 설명 길이와 핵심 정보의 균형. 목표 사용자에게 가까운 질문을 만들고 학습 데이터와 분리한다. 영어 수학 지표는 한국어 설명 품질 전체를 대표하지 않는다. 적절한 네 기준 각 1점, 독립 평가와 지표 범위의 한계 설명 1점. 동등하게 타당한 다른 기준도 인정한다.

</details>

## 11. 모델 심사 결과 해석

LLM 심사자는 A를 B보다 80% 선호했다. A의 정답률이 80%라고 보고해도 되는가? 더 신뢰할 만한 평가를 위해 무엇을 추가하겠는가?

<details><summary>해설과 채점 기준</summary>

안 된다. 상대 선호 비율과 절대 사실 정확도는 다른 지표다. 둘 다 잘못된 응답인데 A가 덜 나쁠 수도 있다. 답변 순서 교환, 모델 이름 가리기, 명시적 기준, 사람 검토 표본, 별도 사실 검증 등을 추가한다. 지표 구분 2점, 가능한 실패 1점, 타당한 개선안 두 개 2점.

</details>

## 12. 보상 모델 점수의 이동 불변성

chosen/rejected 점수가 각각 (2,0)과 (102,100)일 때 sigmoid 선호 확률과 손실을 비교하라. 보상 모델의 102점은 2점보다 51배 좋은가?

<details><summary>해설과 채점 기준</summary>

두 경우 모두 차이가 2이므로 선호 확률은 약 0.880797, 손실은 약 0.126928이다. 이 쌍별 목적에서 공통 상수 이동은 결과를 바꾸지 않는다. 절대 점수 비율로 품질을 해석할 근거가 없다. 차이 계산 1점, 확률·손실 2점, 해석 2점.

</details>

## 13. DPO의 네 로그확률

기준 모델 chosen=-4, rejected=-5, 학습 모델 chosen=-3, rejected=-5.5이고 β=0.1이다. Δ, βΔ, DPO 손실을 구하라. 기준과 학습 모델이 같을 때는 얼마인가?

<details><summary>해설과 채점 기준</summary>

chosen 변화는 1, rejected 변화는 -0.5이므로 Δ=1.5, βΔ=0.15다. 손실은 `-log sigmoid(0.15)≈0.620957`이다. 두 모델이 같으면 Δ=0이므로 `log 2≈0.693147`이다. 변화량과 Δ 2점, 손실 1점, 동일 모델 결과와 이유 2점.

</details>

## 14. 현재 선호와 기준 대비 선호

응답이 두 개뿐인 교육용 정책에서 학습 모델 P(chosen)=0.65다. 기준 모델 P(chosen)가 0.35일 때와 0.90일 때 DPO의 Δ 부호가 어떻게 다른가? 현재 모델이 chosen을 더 선호한다는 사실만으로 충분한가?

<details><summary>해설과 채점 기준</summary>

Δ는 `logit(0.65)−logit(q)`다. q=0.35이면 양수, q=0.90이면 음수다. 둘 다 학습 모델의 chosen 확률은 0.5보다 크지만 기준 대비 선호 이동의 방향은 다르다. DPO는 이 기준 대비 상대 변화를 계산한다. 부호 각 1점, 식 1점, 현재 선호와 상대 변화 구분 2점.

</details>

## 15. DPO 데이터 디버깅

두 응답의 차이는 마지막 문장에만 있다. 최대 토큰 길이 때문에 그 문장이 양쪽 모두 잘렸다. 또한 프롬프트가 chosen 문자열의 앞에 다시 붙었다. 어떤 문제를 일으키는가?

<details><summary>해설과 채점 기준</summary>

잘림 후 응답이 같아지면 선호 차이를 학습할 근거가 사라진다. 프롬프트 중복은 의도한 조건·응답 경계를 깨뜨리며 길이와 손실 대상도 잘못 만들 수 있다. 토큰화 후 응답 비교, 프롬프트/응답 분리, 마스크, 길이 분포를 검토하고 비교 차이가 남도록 데이터를 구성한다. 문제 두 개 각 2점, 검토 방법 1점.

</details>

## 16. 어댑터 계보 디버깅

기반 모델 B에 SFT 어댑터 S를 적용한 B+S에서 DPO 어댑터 D를 학습했다. 배포 담당자는 작은 D 파일만 B에 적용했다. 왜 학습 때와 같은 모델이라고 할 수 없는가?

<details><summary>해설과 채점 기준</summary>

D는 B+S를 출발점으로 학습한 변화량이다. 배포한 B+D에는 S가 빠져 있어 기준 가중치가 달라진다. B에 S를 적용한 모델을 복원한 뒤 D를 적용해야 계보가 맞는다. 기반 체크포인트, SFT 어댑터, DPO 어댑터, 토크나이저·템플릿을 기록한다. 출발점 의존성 3점, 복원·기록 방법 2점.

</details>

## 17. 응용 설계 사고 과제

“항상 길게 설명하는 모델”을 “사용자 요청에 맞는 길이로 설명하는 모델”로 바꾸고 싶다. SFT 사례 하나와 선호 쌍 하나를 설계하고, 단순히 짧은 답변만 chosen으로 고를 때의 위험을 설명하라.

<details><summary>해설과 채점 기준</summary>

SFT 예시는 “한 문장으로 설명하라”에 정확한 한 문장을 주거나 “예시 두 개로 상세히 설명하라”에 충분한 구조를 주는 식이다. 선호 쌍은 동일한 요청에서 필요한 정보를 담은 적절한 길이의 답을 chosen, 요청보다 과도하거나 부족한 답을 rejected로 둔다. 항상 짧은 답만 chosen이면 질문과 무관한 길이 편향을 학습할 수 있다. SFT 1점, 같은 질문의 타당한 쌍 2점, 위험 1점, 요청별 평가 제안 1점.

</details>

## 18. 결과 보고의 정확성

CPU 실습에서 DPO 손실이 0.693에서 0.646으로 줄었다. “DPO가 모델의 실제 답변 품질을 개선했다”고 보고하려 한다. 보고 문장을 고치고 실제 품질 주장을 위해 필요한 증거를 적어라.

<details><summary>해설과 채점 기준</summary>

“질문 하나와 두 응답으로 제한한 가상 정책에서 DPO 목적함수를 경사하강으로 최적화하여 손실 감소를 확인했다”가 정확하다. 실제 모델의 독립 질문, 동일 생성 설정의 전후 비교, 목표 사용 사례의 채점 기준, 오류 유형·사람 또는 검증된 자동 평가가 필요하다. 범위 제한 3점, 필요한 평가 증거 2점.

</details>

## 복습 기준

틀린 문제가 많았던 묶음을 다시 읽는다. 1–3은 SFT와 데이터, 4–9는 효율화와 학습 설정, 10–12는 평가·보상, 13–18은 DPO와 실제 실험 설계에 해당한다. 정답을 외우기보다 각 계산에서 “무엇이 고정되고 무엇이 변하는가”를 표시해 보자.
