## 수업에서 남겨야 할 세 가지 결과물

## 0–7분 도입

칠판에 다음 두 응답을 적는다.

- 요청: “언어 모델을 한 문장으로 설명해 주세요.”
- 응답 A: “언어 모델의 종류에는 무엇이 있을까요?”
- 응답 B: “언어 모델은 문맥을 바탕으로 언어의 패턴을 예측하고 생성하는 모델입니다.”

“어느 쪽이 더 그럴듯한 문장인가?”와 “어느 쪽이 요청을 수행했는가?”를 따로 묻는다. A도 문법적 문장이지만 요청 수행은 B가 낫다. 이 차이를 통해 언어 모델링과 지시 수행의 목적을 구분한다.

**카드 활동:** `책과 웹 문장`, `질문과 모범 답변`, `같은 질문의 두 응답과 선호 표시`를 세 학습 단계에 배치한다. 학생이 SFT를 “사람 피드백” 전체와 혼동하면 “좋은 답안 하나를 보여 주는가, 두 답안을 비교하는가?”로 되묻는다.

**판서:** `텍스트 → 기반 모델 → 지시 데이터 → SFT 모델 → 선호 쌍 → 선호 튜닝 모델`. 단계가 모든 시스템의 고정 규칙은 아니라는 점을 말하고, 이 장의 설명 틀임을 밝힌다.

## 7–17분 SFT 손실과 마스킹

판서할 수식은 하나로 제한한다.

```text
응답 손실 = -평균(log 정답 토큰 확률)
```

정답 확률 `[0.8, 0.5, 0.25]`를 주고, 전체 응답 확률 `0.1`, 평균 NLL `0.7675`, PPL `2.1544`를 연결한다. 학생에게 “확률을 더하면 왜 안 되는가?”를 묻는다. 조건부 확률을 곱한 것이 응답 확률이며 로그를 취하면 합으로 바뀐다는 답이 나와야 한다.

**마스크 활동:** `[사용자, 질문, 어시스턴트, 정의, 예시, EOS, PAD]` 일곱 칸을 그린다. 응답만 학습하는 설정에서 `[0,0,0,1,1,1,0]`을 표시하게 한다. 질문 토큰에 0을 썼다고 모델 입력에서 질문이 지워진 것은 아니라는 점을 설명한다.

**오해 확인:** “SFT는 정답을 넣으니 추론 때도 정답을 알아야 한다”는 문장을 고치게 한다. 훈련에서는 정답 이전 토큰으로 예측을 연습하고, 추론에서는 자신의 생성 토큰을 사용한다.

## 17–32분 LoRA를 행렬로 이해하기

먼저 W₀의 크기를 4×6으로 적고 학습 여부에 “고정”이라고 표시한다. 그 옆에 rank 2의 B는 4×2, A는 2×6임을 적는다. 학습 파라미터는 `8+12=20`개, 전체는 24개다. 큰 모델의 예시로 옮기면 `12,288²`과 `2×12,288×8`을 비교할 수 있다.

**판서 질문:** “A를 6×2로 적으면 무엇이 잘못되는가?” 열벡터 입력 convention에서 A의 입력 차원이 6이어야 하므로 2×6이 맞다. 행벡터 convention을 쓰면 전치할 수 있지만 한 도식 안에서 혼용하면 안 된다.

**손계산:** B를 `[[1],[2]]`, A를 `[[3,4,5]]`로 주고 BA를 계산한다. 두 번째 행이 첫 행의 두 배라는 사실을 보고 rank 1의 제약을 설명하게 한다. 이때 “작은 두 행렬이 아무 큰 행렬이나 정확히 복원한다”는 오해를 잡는다.

**시각 실험:** rank를 1→2→4로 바꾼다. 화면의 기반 크기는 6×8, 따라서 r=4일 때 56개의 변경 파라미터가 전체 48개보다 많아진다. 이 수치는 수업의 4×6 판서와 차원이 다르므로 화면의 차원을 다시 읽게 한다. 목적은 손실 없는 압축이 아니라 적절한 변화 공간의 선택이다.

## 32–43분 QLoRA와 양자화

“메모리에 저장된 코드”와 “계산할 때 쓰는 수”를 다른 칸으로 그린다. 4비트 저장은 16개 코드이며, 실제 행렬 계산 dtype은 더 높을 수 있음을 설명한다. LoRA는 학습 대상의 수를 줄이고, 양자화는 기반 가중치의 저장 비용을 줄인다는 두 축을 분리한다.

**시각 실험:** 2비트와 4비트를 비교하고, 8.0 이상값이 처음 네 값의 전역 복원에 미치는 영향을 관찰한다. 블록별 방법에서는 첫 블록이 영향을 덜 받는다는 결론을 유도한다. 그림이 NF4 구현은 아니며 균일 양자화의 원리 실험임을 반드시 말한다.

**확인 질문:** “블록별로 나누면 비용 없이 완벽해지는가?” 기대 답은 “오차가 줄어들 수 있지만 스케일 메타데이터 비용이 있고 모든 차이를 보존하지는 않는다”이다. 이어 NF4, double quantization, paged optimizer의 서로 다른 역할을 한 문장씩 설명한다.

## 43–53분 학습 코드를 읽는 법

다음 오류 카드 네 개를 보여 주고 두 사람씩 이유를 적게 한다.

1. `cosine`만 설정했으므로 warmup도 켜졌다고 판단한다.
2. 모델 로드에 1GB였으므로 훈련도 1GB로 충분하다고 판단한다.
3. SFT 어댑터 파일만 저장하면 기반 모델 없이 추론할 수 있다고 판단한다.
4. 병합 모델을 다른 변수에 저장했는데 학습기에는 이전 객체를 넘긴다.

**기대 답:** warmup은 별도 인수, 훈련에는 활성값·학습 상태, 어댑터는 원래 가중치 필요, 실제 객체의 계보 불일치다. 코드의 주석과 실행 동작이 다를 수 있으므로 텍스트를 그대로 믿지 않고 가중치·데이터·설정의 흐름을 추적하게 한다.

유효 배치 `2×4=8`, DPO 200 step에서 warmup 10%는 20 step이라는 계산을 함께 확인한다. 한 epoch와 optimizer step의 차이도 짧게 묻는다.

## 53–64분 평가표 만들기

**과제:** “한국어 초보자에게 LLM 개념을 설명하는 도우미”의 평가표를 4개 항목 이상 만든다. 권장 항목은 사실성, 용어 설명, 예시의 타당성, 요구 형식, 불필요한 장황함이다. “친절함 10점” 같은 모호한 항목은 관찰 가능한 기준으로 바꾸게 한다.

같은 정답을 담은 짧은 답변과 긴 답변을 보여 주고 상황에 따라 선호가 달라지는지 토론한다. 그다음 PPL, 공개 벤치마크, 모델 심사, 사람 심사 중 어떤 증거가 필요한지 연결한다.

**교사 설명:** PPL은 정답 텍스트 예측, HumanEval은 코드 과제, GSM8K는 수학 문장제처럼 측정 범위가 다르다. 리더보드 평균은 목표 사용 사례를 대체하지 않는다. 모델 심사는 확장 가능하지만 편향과 오판이 있고, 사람도 기준과 표본 설계가 필요하다.

## 64–75분 선호와 보상 모델

같은 질문의 두 응답을 주되 둘 다 정답으로 만든다. 한쪽은 초보자에게 지나치게 어렵고 다른 쪽은 설명이 명확하다. 학생에게 rejected가 “완전히 틀린 답”이어야 하는지 묻는다. 상대 선호와 절대 정답을 분리한다.

판서: `r+=2, r-=0`, `r+=102, r-=100`. 두 경우의 sigmoid 점수 차이와 손실이 같음을 확인한다. 보상 모델의 스칼라는 곧바로 정확도나 만족도 백분율이 아니라는 결론을 이끈다.

**그림 활동:** 학생이 `선호 수집 → 보상 모델 학습 → 생성 모델 학습`을 그리게 한다. PPO의 세부 수식을 외우게 하기보다 보상을 높이면서 정책 업데이트를 제어한다는 역할과 별도 보상 모델의 비용을 설명한다. 도움됨·안전성 점수가 충돌하는 상황도 한 사례로 논의한다.

## 75–86분 DPO와 실습

네 로그확률을 칠판의 2×2 표에 적는다.

| | chosen | rejected |
|---|---:|---:|
| 기준 모델 | -4 | -5 |
| 학습 모델 | -3 | -5.5 |

학생은 열별 변화 `+1`, `-0.5`를 구하고 두 변화의 차이 `1.5`를 계산한다. β=0.1이면 손실은 약 0.621이다. “chosen의 로그확률이 높다”와 “기준 대비 더 선호하게 되었다”가 다른 질문임을 강조한다.

CPU 실습을 실행하여 DPO의 초기 손실 약 0.693, 마지막 손실 약 0.646을 확인한다. 이것은 단일 가상 정책의 목적함수 감소이며 실제 LLM 품질 향상의 증거가 아니라는 말을 학생이 직접 하게 한다.

마지막으로 SFT 어댑터와 DPO 어댑터의 병합 순서를 그린다. DPO 어댑터가 학습된 출발점은 SFT 모델이라는 전제를 확인한다. ORPO는 모방과 선호 목표를 한 학습 흐름에서 다루는 확장이며 DPO 손실을 그대로 붙이는 동일 알고리즘은 아님을 짚는다.

## 86–90분 퇴실 문제

1. “QLoRA는 모든 파라미터를 4비트로 학습한다”를 올바르게 고치기.
2. 학습 모델과 기준 모델이 같을 때 DPO 손실을 쓰고 이유 설명하기.
3. 손실은 줄었는데 사람이 평가한 품질이 나빠지는 가능한 원인 두 가지 쓰기.

**기대 답:** 고정된 기반 가중치의 저비트 저장과 LoRA 학습을 구분한다. 기준과 같은 경우 Δ=0이므로 log 2다. 데이터 선호 편향·과적합·목표 불일치·평가 조건 차이 등을 구체적으로 설명한다.
